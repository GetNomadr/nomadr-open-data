# Nomadr Open Data: 338 Places for Digital Nomads

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24550778.svg)](https://doi.org/10.5281/zenodo.24550778)

Free download of Nomadr's headline facts for every place we cover.

## Fields

| Field | |
|---|---|
| `city` | Place name |
| `country` | Country or territory |
| `region` | Nomadr region |
| `url` | The place's Nomadr page |
| `typical_month_usd` | Mid-range month in US dollars: housing (estimated short-stay), food, transport and mobile |
| `cost_status` | researched, or nomad_adjusted where the page shows the month adjusted for nomad prices |
| `safety_tier` | Violent crime level (violent crime only) |
| `digital_nomad_visa` | yes, no or not_stated, as this place's page states it |
| `digital_nomad_visa_name` | The visa's name where stated |
| `country_digital_nomad_visa` | yes where any place in the country states a digital nomad visa, else not_stated |
| `data_updated` | Date of the place's most recent research across the topics in this file (YYYY-MM-DD) |
| `place_id` | Nomadr's ID for the place (the end of its page address) |
| `country_code` | ISO 3166-1 alpha-2 country code |
| `latitude` | Approximate center of the place (decimal degrees) |
| `longitude` | Approximate center of the place (decimal degrees) |
| `rent_furnished_1bed` | Furnished one-bedroom rent per month, as the place's Cost of Living page shows it |
| `rent_furnished_1bed_usd_min` | Low end of that rent in US dollars, where the page gives a US-dollar figure |
| `rent_furnished_1bed_usd_max` | High end of that rent in US dollars, where the page gives a US-dollar figure |
| `coworking_desk_month` | Typical monthly coworking desk, as the Coworking page shows it |
| `coworking_spaces_listed` | Number of coworking spaces Nomadr lists for the place |
| `coliving_month` | Co-living monthly price range, as the Co-Living page shows it |
| `lgbtq_legal_status` | legal_with_protections, legal_no_protections, criminalized or criminalized_in_practice, from the place's LGBTQ+ research |
| `lgbtq_social_climate` | welcoming, tolerant, discreet or hostile, where stated |
| `nomad_scene_size` | major_hub, large, mid_sized, small or minimal, where stated |
| `nightlife_scene` | party_destination, strong_nightlife, moderate_nightlife or quiet |
| `climate_type` | Broad climate type, for example tropical, mediterranean or continental |
| `cost_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `visa_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `safety_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `lgbtq_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `coworking_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `coliving_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `nomad_scene_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `nightlife_updated` | Date this topic was last researched (YYYY-MM-DD) |
| `climate_updated` | Date this topic was last researched (YYYY-MM-DD) |
